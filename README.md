# 共同特点

大部分机场均支持：

* 流媒体解锁（Netflix、Disney+ 等）
* 香港、日本、新加坡、美国、台湾等常用地区节点
* 订阅链接导入 Clash、Shadowrocket、Sing-box、v2rayN 等客户端
* 支持 AI 工具访问
* 具备跨境专线或优化线路
* 新用户建议先购买最低套餐测试
